# FOUNDRESS asset manifest

All textures and 9 of the 45 audio files under `public/assets/` are derived from **CC0 1.0 / public-domain-dedicated** sources. The other 36 audio files are **original sounds rendered by code in this repository** (`tools/audio/`, provenance pass of 2026-11-18); no third-party recording is in them. Raw downloads live in `assets-src/raw/<source>/` (not shipped). Processing scripts: `tools/assets/` (`fetch_polyhaven.py`, `fetch_ambientcg.sh`, `download_list.py` + `downloads.tsv`, `process_textures.py`, `process_audio.py`, `build_manifest.py`). Machine-readable list: `public/assets/manifest.json`.

Totals: 78 texture files (25 materials), 45 audio files, **19.90 MB** in `public/assets` (budget 25 MB; hosting cap 64 MB).

## Licence verification notes

- **Poly Haven** (polyhaven.com/license): "Our assets are all licensed as CC0." Authors listed per asset via `api.polyhaven.com/info/<id>`.
- **ambientCG** (docs.ambientcg.com/license): "All ambientCG assets are provided under the Creative Commons CC0 1.0 Universal License." The asset pages do not name an individual author; credited as ambientCG.
- **OpenGameArt**: every item was checked on its page for a `CC0` licence badge (the one clip from the multi-licence page *Digging Underground* by Almitory was **removed in the licence audit**: the uploader ticked every licence including GPL, with no provenance). Authors are the uploader names shown on OGA; OGA cannot prove the uploader is the original recorder. The nine OpenGameArt audio files that remain are the ones whose page names the author who uploaded it (birds, wind, light rain, fridge hum, gravel step, two crunches, two splats); the OpenGameArt files that came second-hand (the grasshopper trim of a Freesound recording, the tree creak, the water drips, the Kenney UI set, the engine-rumble effect) were **replaced by original sounds on 2026-11-18**.
- **archive.org USC Sound Effect Archive ("Red Library", "SSE Library")**: **removed on 2026-11-18.** The 26 files from these items (provenance tier B: an uploader's CC0 mark over legacy studio tapes, no documented rights chain) were replaced by original sounds rendered in this repository. Each record keeps a `replaces` entry naming the removed source, for the audit trail; none of that material is in a shipped file. The raw downloads under `assets-src/raw/archive/` are local only and git-ignored; nothing reads them.
- **Original sounds (36 files)**: `tools/audio/` renders them from seeded noise, filters, envelopes and resonators (no input recordings); the registry is `tools/audio/sounds/index.mjs`, the records say `provenance: original`. Run `node tools/audio/render.mjs && node tools/audio/sync-records.mjs`; the output is byte-identical on every run.
- **Not reachable / not used:** freesound.org (HTTP 403 from the sandbox, API needs a key), Wikimedia Commons (HTTP 429 rate limit on every attempt), kenney.nl (HTTP 403). No file from any of them ships any more.

## Processing conventions

- Textures: Lanczos resize (1024 for major, 512 for minor; atlases 1024 wide, leaf atlas 1024x512), metadata stripped. Albedo JPEG q82 4:2:0 (atlas q85); normal JPEG q86 4:4:4 (**OpenGL / +Y up**; Poly Haven `nor_gl`, ambientCG `NormalGL`); roughness 8-bit greyscale JPEG q80; atlas opacity = greyscale JPEG q80 (white = opaque). Sources are the 1K JPEG variants (already 1024 px), so no upscaling occurred. Normal quality was lowered from the brief's ~90 to 86 to keep the budget.
- Audio, the nine kept OpenGameArt files: decoded with ffmpeg, excerpted, high-passed at 35 Hz, MP3 libmp3lame 96 kbps CBR, 44.1 kHz; beds loudness-normalised to -24 LUFS, one-shots peak-normalised to -3 dBFS; loops built with a tail-to-head crossfade (`tools/assets/process_audio.py`).
- Audio, the 36 original files (`tools/audio/`): generated at 44.1 kHz (mono, the rumble stereo), loops periodic by construction (noise filtered around the loop, events wrapped) so the last sample flows into the first with no crossfade; **beds -24 LUFS integrated, underground rumble -26, mowers -22, measured on the decoded MP3** (a second encode pass cancels the encoder's own -0.45 dB); one-shots peak -3 dBFS and lowered where needed so their mean K-weighted loudness does not exceed that of the file they replaced (`tools/audio/sounds/old-levels.json`), so the cue gains tuned in the audio pass keep their meaning; true peak below -1 dBFS everywhere. MP3 has about 25 ms of encoder delay (the engine's loop player trims 30 ms at both ends and crossfades). Measurement tables: `docs/design/tasks/audio-provenance-report.md`.
- **I cannot listen to audio in this environment.** Excerpts were chosen from titles, source descriptions, loudness/centroid analysis and spectrograms; each ambience bed's spectrogram was checked visually, but an ear check of every clip is still advisable.

## Other caveats

- Soil/humus/gravel/sand colours differ in white balance (sand is yellow-brown, gravel is cold grey); grade in the material or splat shader if a unified palette is wanted.
- `rubber_playground` (red) comes from an athletics track scan; `rubber_black` is the tyre/gym-mat stand-in.
- `metal_painted` is flaking grey paint over rust (strong, high-contrast); `metal_galvanised` is corrugated steel (ridges tile vertically).
- Leaf/foliage atlases are not tileable; they are intended for cut-out cards. `leaf_atlas_maple` is 2:1.
- Raw sources are kept in `assets-src/raw/` (~620 MB, not part of the 25 MB budget; add to `.gitignore` or Git LFS if the repo should stay small).

## Provenance pass (2026-11-18)

Integrator decision: the game ships no sound whose right to ship rests on an uploader's word about someone else's recording. Removed from the shipped set and replaced by original sounds (ids and cue roles unchanged): the 26 archive.org files (provenance tier B) and ten second-hand OpenGameArt files (`stridulation_grasshopper_01`, `wood_creak_03`, `water_drip_01/02`, `ui_click_01/02/03`, `ui_hover_01`, `ui_switch_01`, plus `ambience/underground_rumble`, whose source was an engine effect, not a recording of earth). Nine OpenGameArt files stay, each on its author's own page with a CC0 badge (`provenance` field of their records). The records of the replaced files carry a `replaces` entry with the removed source. See `docs/CREDITS-AUDIT.md` and `docs/design/tasks/audio-provenance-report.md`.

## Licence and integrity audit (2026-11-12)

Independent re-check of every source page (Poly Haven API + licence page, ambientCG API + licence docs, each OpenGameArt page, archive.org item metadata and file lists). Result: 56 unique source pages checked, 55 confirmed CC0 with matching titles/authors, 1 removed (1 clip); 2 author corrections (3 files); see `public/assets/CREDITS.md`.

- Removed: `audio/sfx/soil_dig_01` (OGA *Digging Underground*, Almitory). The page lists CC-BY, CC-BY-SA, GPL, OGA-BY and CC0 simultaneously (a sign the uploader does not own or understand the rights) and gives no recording provenance.
- Author corrections: `water_drip_01/02` are credited on OGA to *Independent.nu* (submitted by qubodup); `wood_creak_03` is a Department64 recording cleaned up by AntumDeluge.
- Tier B (archive.org USC libraries, 17 items / 26 files): the CC0 marking is real and visible on the item pages (`licenseurl`, "CC0 1.0 Universal"), but it is an uploader assertion over legacy studio tapes with no documented rights chain.
- Known defect, not fixed here: all 12 loop files start with ~5 ms of near-silence (the `alimiter` lookahead in `process_audio.py` delays the signal and truncates the tail), so each loop point has a ~5 ms dropout; `underground_rumble` also has a wrap step of about 1.5x RMS.
