# GDD deviations and integrator rulings

Where the game differs from the design document (`docs/design/gdd/`), and why. Written 2026-11-18 from the repository at commit `fb15f3d`. The GDD chapters were not edited; section "GDD passages that are now wrong" lists what should be amended.

Sources, in this order: `docs/STATUS.md` (rulings R1 to R28 and the dated log), the rulings' own task specs (`docs/design/tasks/viab-economy.md`, `econ-growth.md`, `nest-fix3.md`, `colony-life.md`), the task reports and review notes (`docs/design/tasks/*-report.md`, `notes-1A.md`, `notes-1B.md`, `notes-foundation.md`), and the colony-life ledger (`docs/design/tasks/colony-life-ledger.md`, sections "GDD deviations"). Precedence when sources disagree: design seed, design directions (sections J and K), GDD `00-index.md`, the chapter that owns the topic, other chapters. Rulings of the integrator come after the directions and take precedence over the chapters.

The rulings in `docs/02-design-directions.md` section K (for example speeds, custom rules, the species availability rule) are binding design decisions made before the GDD index, not deviations from it. They are not repeated here.

Row fields: **Id** (R = integrator ruling; D = other deviation), **Date** (of the ruling or the report that recorded it), **GDD says**, **Game does**, **Why**, **Code** (file and symbol; each pair was checked by search on 2026-11-18), **Test** (the file that pins it; "(long)" tests run only with `FOUNDRESS_LONG=1`). **Status** says whether the rule is built.

Three rulings are written down but **not built**: R13, R14 and R28 (status column). R19 and R22 are acceptance bars for the simulation sweeps, not game rules, and are not met.
