# Digest of GDD 01 — Modes, possession, controls, camera and action primitives

Source: `docs/design/gdd/01-modes-controls-camera.md` (788 lines, ~14,000 words). Binding for `src/game/**`, `src/input/**`, `src/render/camera/**`, `src/sim/ants/actions/**`, `src/sim/ants/player-control/**`. Depends on seed 1-5, directions A, C, D, F, I, J, and 03-architecture.

## 1. Scope

Specifies application flow (screens), the five-view state machine, possession rules (who, how, sim effect, release/inference table, death), player locomotion, the full default control scheme with rebinding and edge cases, camera rigs for every view, the shared action-primitive lifecycle and catalogue (38 primitives), time-speed rules per view, context prompts, inspect read-outs, state/commands/events/diagnostics appendices, 25 acceptance checks, and cross-chapter assumptions. All balance constants live in `src/sim/balance/player.ts` (sim-side) or `src/game/config/camera.ts` / `src/input/defaults.ts` (presentation-side). Units: L = body length of ant in BU; game s scale with speed; real s/ms do not.
