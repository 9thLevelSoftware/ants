## 8. Cross-chapter assumptions (App F, faithful)

1. Progression provides `Diagnostic` records (contracts shape, statuses ok|warn|bad), the ids in 4.4, cause references between diagnostics, entity refs for "Show", remedy ids mappable to UI controls; statistics hourly 7 days and daily all time; milestones; event log; final cause chain on game over.
2. Sim raises/clears alerts with game-time hysteresis, setting kind, level, subjectId, title, cause, focus, diagnosticId; thresholds per kind defined by owner chapter named in 6.5.
3. Colony defines allocation as four groups (forage, nurse, dig, defend) mapped as in 4.2, "auto" allocation, production modes, diet emphasis -100..+100, accepts `setDirectives` while paused; if different groups, Directives follows its groups with same control rules.
4. Markers define `MARKER_CAP[kind]`, radius ranges compatible with 8-64 BU, validity reasons; nest defines dig templates (chamber, tunnel, shaft, entrance; sizes 8/12/16 BU), wall anchoring, `status` values compatible with 4.3 (proposed, queued, active, stalled, complete) and `blockedReason` strings.
5. Founding (GDD 06 s5) provides site assessment (seven factors), readiness (shaft depth + chamber volume), seal and lay steps, reserves 0..1, nanitic outcome, interruption events; time-lapse driven by sim with `player.timelapse`.
6. Environment provides sun elevation, surface temperature per point, soil moisture, cavity humidity, weather states, human-event warnings with warning phase and area, winter time-lapse data.
7. Possession provides action availability per frame with priorities, crop capacity, acid reserve, heat stress, possessed-ant death handling.
8. Ecology provides creature kinds for comfort mode, territories for threat overlay, cue emission for creature actions.
9. Worldgen: archetype ids `woodland-edge`, `suburban-garden`, `playground-park`, `car-park-verge`, `kitchen-door`; size ids `compact|standard|large`; uint32 seeds; staged progress matching 3.6; cheap zone-layout-only entry for preview; up to 8 generation attempts (`WORLDGEN_MAX_ATTEMPTS`).
10. Species data provides `available`, `foundingSeason`, plate/turntable model, complexity rating, founding style word, per-species cue choices (drum vs stridulate).
11. Persistence: IndexedDB saves with `auto` (2 generations) + 5 slots, binary export with magic header, version, checksum; accepts `FOUNDRESS1:` + base64.
12. Rendering supports clip-plane cutaway with caps, X-ray, overlay passes from sim fields, creature render variants for comfort mode, photo camera with sphere-traced collision.
13. Season-length custom rule honoured by calendar (`DAYS_PER_SEASON` a game-config value); otherwise option hidden.
Additional implicit dependencies in body: GDD 01 (`fovOffset`, `cv-cutaway-mode`, `cv-slice-up/down`, `cycle-target`, `possess-last`, pose.* ids, s6.6 ambient watch, s6.7 rig, s2 hand-over); GDD 02 (s12.2 marker radius, s13.2 series ids, App A `colonies[]`, S3 starvation); GDD 03 (s4, s12 collapse, App B); GDD 05 s3.7 rival states, `raid`; GDD 06 (s1.6 founding day, s5.3, s5.7, s5.13 aims, s9.2, s10 codex, s11.3, s12, s13.4, s14.1, s15 autosaves, `dayOfSeason`, SIM_FRAME_BUDGET_MS); GDD 07 (s1 release order, s2.6, s3.14 `directiveTasks`, s3.15 `appearance`, s6.2-6.4); GDD 04 (human events, s4.1 budget).

## 9. Deviations and oddities

Against seed/directions:
- No per-agent weight "w" used. No W_eq. Colony thresholds not stated here. 1500 / ~2500 caps quoted consistently with K.
- Unit conversion: `CALLOW_DARKEN_GAME_H = 6` is a compression of the dossier's 3-4 real days (genre-ux said "about an hour"); the only explicit conversion.
- Calendar: all dates shown as `Season · Day n · Year y` with day-of-season (1..season length); natural start "Summer · Day 3 (afternoon)" for Lasius; custom `startSeason` starts on day 3 of that season; winter start disabled. No different anchors from K, but day-of-season display depends on configured season length.
- Directions I says stridulation generic; chapter restricts `stridulate` to Messor/Atta, `drum` to Camponotus, none for Lasius.
- Directions J has no `raid` task or rival state ids; chapter references `raid` (GDD 05) and `peace/tension/skirmish/war/truce`. Alert kind list, overlay ids, screen ids are additions to J.
- Directions I minimap, scent view, etc. kept; adds `diag-*` presentation diagnostics.
- Display rule bans "war/battle/victory/truce/enemy" in player-facing text even though ids keep `war`/`truce`.
- Formicine pupae in cocoons / myrmicine naked noted as brood rendering rule.

Internal contradictions / hard-coded numbers noticed:
- Autosave ring: 7.6 says `auto` = 3 generations; Appendix F item 11 says 2 generations.
- Generation retries: 3.6 loading label "attempt 2 of 5"; Appendix F item 9 says up to 8 (`WORLDGEN_MAX_ATTEMPTS`).
- Hint dismissal key: 9.1 says Backspace / hold Y; 5.4 says Shift+H (and notes Backspace is GDD 01 `possess-last`).
