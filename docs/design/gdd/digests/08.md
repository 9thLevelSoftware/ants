## 9. Deviations and oddities

**Stated deviations:** (a) `stridulate` cue only Messor/Atta, `drum` Camponotus, Lasius neither (directions I lists generic stridulation). (b) Formicine pupae in cocoons, myrmicine naked. (c) Callow darkening: dossier 3-4 days compressed to 6 game h (genre-ux said ~1 h). (d) UI scale 80-150 % (+ text size to 130 %; genre-ux said 75-200 %). (e) Lasius default start season Summer, not Spring.
**Per-agent weights `w`:** none used; roster counts individual ants (2500 rows), consistent with K.
**Unit conversions:** none introduced; times quoted in game h / real s explicitly. Directions J's 25 real s per game h used.
**Calendar:** dates written as `Season · Day n · Year y` with n appearing to be day-of-season (Day 1-7?) but examples include "Day 5", "Day 4"; K defines game day 1-28 per year with season = 7-day blocks. Not stated whether n is day-of-season or day-of-year. Chapter 06 defines `dayOfSeason`. New Game starts Day 1 of the chosen season ("Summer, Day 1"), not K's "species' natural founding day set by ch 06"; starting season list Spring/Summer/Autumn/Winter-disabled offered freely, whereas ch06 says it is "restricted to the species window" with the seed picking the day. Season-length custom here 5/7/10; ch06 lists 4/7/10/14. Journal graph range "last 28 days (year)" assumes 28-day year.
**Internal oddities / contradictions:**
- Gamepad D-pad left both "hold 0.5 s = pause" and "step speed down"; Zoom row uses LB hold (>250 ms) while LB is also "previous ant".
- Q/E mean: tab switch in menus, camera rotate 45 deg in colony view, ghost rotate 15 deg in dig tool, down/up in photo mode; Q also bound to Bite. Shift+1..4 quick-possess vs Shift+1..7 marker tools (layered).
- `setAutoExpand {on}` command exists in Appendix B but Directives section only exposes "Nest architect Auto/Off" via `setDirectives.architect`; relation unclear.
- Alerts `info` have no toast yet `audio-blocked` info alert and codex "info" toast exist (toast 4 s exception). `milestone`/`source-exhausted` info only logged.
- Pause menu opens Journal/Codex (book screens that pause) while Esc closes drawers first.
- Title table lists Credits as T1 screen but Codex "only unlocked entries" on title; Lineage hidden vs disabled.
- Roster spec says "up to 2500 rows" while K caps player colony at 1500 workers (2500 is total across colonies); roster id padded to 4 digits.
- Acceptance check 2 states expected `compact` layout at 150 % (1280/1.5 = 853 dp) which contradicts 960x540 standard threshold only if intended as example; consistent but means 150 % always forces compact at 720p.
- Autosave "every interval of real play time" vs deferral up to 30 s in combat.
- Both T1 table row "Settings graphics ... Auto detection T3" while quality preset Auto default.
**Stated as unresolved / assumption:** spike-look and spike-ants results pending (section 11 are targets); Messor major tint "unverified"; whether `rally` has Defend vs Gather depends on combat chapter; "Seal entrances in cold weather" only if nest chapter provides; marker caps, diag ids owned elsewhere; `HINT_DELAY_REAL_S` value unspecified; time-lapse fill (ticking vs analytic) left to founding/environment chapters; player.timelapse shape "assumed"; statistics sampling "assumed"; alert hysteresis owned by sim; provenance tier B audio files may be missing (synth fallbacks).
