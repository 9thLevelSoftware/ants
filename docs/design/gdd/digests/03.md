## 6. Diagnostics (D)

Record `{id, system:'nest', status, label, value, factors[{cause,weight,detail}], remedies[], sinceTick}`; statuses `ok|info|warn|bad`; weights normalised shares.

| Id | Status | Factors |
|---|---|---|
| `diag-dig-progress` (per plan) | ok rate ≥ 70 % of slot potential; warn < 70 % or `no-haulers`; bad `stalled` | diggers short (1−assigned/slots); haul bottleneck; hard substrate (1−min(1,digSpeed)); temperature (1−workRate); clutter (1−multiplier); flooding; obstruction |
| `diag-nest-space` | ok ρ ≤ 0.85, ρ_b ≤ 0.8, food ≤ 0.8; warn any above; bad ρ ≥ 1.3 or ρ_b ≥ 1.3 | adult crowding; brood space; food space; architect off; no diggers |
| `diag-nest-climate` | ok best brood score ≥ 0.8; warn ≥ 0.5; bad < 0.5; plus GDD 06 per-chamber rule (warn outside [Topt_lo−4, Topt_hi+4]; bad < 10 °C or > 36 °C), worst of both | too cold/hot/dry/humid; no cover; nursery too shallow/deep |
| `diag-nest-flood` (T2) | ok none predicted; warn predicted; bad flooding now | exposed entrance (c, f_cover); low rim; crusted run-off; clay drainage; low brood chamber; "rain forecast" (folded from GDD 06 `diag-flood-risk`) |
