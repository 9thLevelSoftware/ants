# Digest of GDD Chapter 02: Colony simulation (Lasius niger reference)

Source: docs/design/gdd/02-colony-simulation.md (about 16,400 words). Units: BU, game seconds (s), game days (gd, 1 gd = 600 s = 6000 ticks), loads (C, P), lm (load-mass unit, 1 lm = a standard solid item one worker carries), ph (pheromone units), DU (development unit, 1 DU = 1 gd at 21 C). A per-gd rate is applied per tick as `rate*0.1/600`.

## 1. Scope

The chapter specifies the colony simulation for the reference species: individual ant physiology, brood, queen, food and nutrition economy, task allocation, perception, pheromones, navigation memory, per-task behaviour state machines, cooperative transport, colony directives and markers, statistics, diagnostics, a worked example, acceptance checks. It consumes (does not own) locomotion, Tb/speedMult, carve grid/chambers, food sources, combat, alates/queen death/overwinter/opening (ch 06), possession (ch 01). Tiers T1/T2/T3 per row; a row inherits its section tag.

## 9. Deviations and oddities

Declared deviations (D1-D10): D1 AI cruise 6 BU/s, 12 BU/s as run/alarm max (agrees with K); D2 upkeep numbers per J are far below real cost, gameplay economy; D3 brood split 1.4/0.6/1.9 gd at 21 C; D4 Gordon (Pogonomyrmex) interaction model used without patroller gate; D5 brood-protein regulation analogy (Rhytidoponera), excess-P lifespan penalty T3; D6 no repletes, colony pool = social stomach plus piles; D7 allocation reads colony aggregates (abstraction); D8 75-worker recruitment threshold is smooth sizeFactor; D9 starvation cannibalism not measured for L. niger; D10 directives/markers are an abstraction of decentralised control, never move ants directly.

Checks requested:
- Per-agent weight "w": none in the K sense (no "one agent = N ants", no W_eq, no real-worker thresholds). Name clash only: `w_lead`, `wC`, `wP` are nutrient weights (5.5), not agent weights; a naive "w" grep would false-positive. All thresholds are in simulated workers (N>=40, 75, 100/250, caps 1500).
- Unit conversions: lifespans quoted with real-day equivalents at about 13 real days per gd (33 gd = 434 real days, 24 gd = 309). Code applies no conversion (rate x0.1/600 only).
- Calendar: D = doy + hour/24, 1-based; ch 06 `d` is 0-based (d = D-1). fSeason breakpoints (days 2, 5, 15, 18, 21, 29) and DIAPAUSE_DOY 19 are written as 28-day-year day numbers; the chapter does not state they are scaled by configured season length (K requires year-fraction storage). Worked example uses "Summer day 9".
- Round-trip: J says ~600 BU trip about 2 real min returning 1 load; chapter 10.2 gives about 2.5 min and defaults yieldPerForager 1.5 loads/gd per forager, example yield 2.2 (slightly above J order of magnitude on yield, not trip count).
- MET_LIGHT 0.12 C/gd is new (J has only 0.08/0.20). Founding upkeep 0.40 = 0.30 C + 0.10 P.
