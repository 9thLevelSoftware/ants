# Note on Stage 2 and Stage 3 task specs

These specs are shorter than the Stage 1 ones on purpose: by Stage 2 the module APIs exist and are documented in code, and the GDD chapters carry the rules. Each spec gives the goal, what to read in full, exclusive ownership, boundaries and acceptance criteria. The common rules in the build workflow preamble apply unchanged (file ownership, verification by running, GDD precedence, Appendix E checks).
