## Work
1. **Plans.** Plan bounds are a cube about 4.75 times larger than the plan's shapes need, which inflates validation and the plan cache; make them tight. `acceptPlan` is a no-op handler: implement it per the design or remove the command if the design has none (say which). The architect's layout for a 400-worker nest takes 82 ms against a 50 ms budget: with tight bounds and incremental navigation rebuilds bring it inside the budget (measure several times, take the minimum; the machine is loaded).
2. **Spoil and passages.** Pellets left in a pile inside the nest tamp after 1200 s and can then close a 2 BU neck. The design does not want a nest that walls itself in: make sure spoil inside the nest is offered for hauling with rising urgency, and that tamping never narrows a passage below what the species' workers need (state the rule you implement and where the design supports it). Add the query the haulers lack — the deepest dead-end tunnel tip at least 6 BU from any chamber (GDD 03 §7.7, internal dump) — and the `midden-blocked` flag with its alert.
3. **Mounds.** A mound batch costs 40-90 ms per 250 ticks per mound since the 8-neighbour relaxation: spread the work over ticks or make it incremental so no single tick pays more than the nest system's share of the budget; the mound's shape and volume conservation tests must still pass.
4. **Entrances.** Raise an alert/event when an entrance closes without a plug (soil slumping or a mound burying it), with the cause, so the interface can tell the player.
5. **Colony seams.** A public count-only delivery function (statistics, source ledger, yield estimate and the `delivery` event, without a second deposit), so the foraging adapter can stop importing colony internals. `cheat.injectReturn` must reach foragers waiting in the entrance chamber (use the design's wait radius). The `stores-full` alert after the design's delay. The allocator must not reassign an ant that is outside on an outdoor task until it is home. A ledger key for the departure ration.
6. **Tier 1 sources.** Static spills evaporate with a half-life of 0.15-1 game day and carrion is removed after 3 game days: check both against the design's Tier 1 rules and the economy floor (`00-index.md` C13) and fix whichever side is wrong (list changed values, old -> new, with the section).
7. **Hygiene.** `src/sim/balance/index.ts` re-exports every balance file (foraging, nest-work and architect are missing); the nest-space diagnostic reads the architect's own need cache; load-dependent timing tests in your folders get a load-tolerant bound plus a strict mode behind `FOUNDRESS_PERF_STRICT=1`; the red tests reported in your folders (`stage1a.verify` nest save/load, anything under `src/sim/nest` or `src/sim/colony` that fails in default mode) are fixed at their root.

## Acceptance criteria
1. `npm run typecheck` clean; all tests under `src/sim/nest`, `src/sim/colony` (except `founding`), `src/sim/ecology` green in default mode (files cheap: about 20 s each on an idle machine; large sweeps behind `FOUNDRESS_LONG=1`).
2. Plan bounds: a test shows bounds within one voxel of the shapes' extent; validation and layout timings before and after are reported; the 400-worker layout is inside its budget on a quiet run or the remaining cost is itemised.
3. A scenario test: a nest dug for 2 game days by 60 workers with hauling throttled never loses connectivity between any chamber and an entrance through tamping; with no open entrance the dead-end query returns a valid tip and `midden-blocked` is raised.
4. Mound work per tick is bounded (report the maximum per tick before and after); conservation and shape tests pass.
5. The new colony functions each have a test; the `stores-full` alert and the entrance-closed alert fire in a scenario and not otherwise.
6. Determinism and save/load equality hold for every state you added.
