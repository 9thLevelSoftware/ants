## Work (in this order)
1. **The locomotion stall.** An autonomous walker with a point goal inside the nest often stands still for seconds with `nav.status` 'moving' and speed 0: near goals 0.4-2 BU away, when a requested move is smaller than one nest voxel (0.5 BU), and when upside down on a tunnel ceiling with the target below. A fresh request restarts the recovery ladder, so callers cannot cure it. Reproduce each case in a locomotion-level test first (use the in-nest behaviours' measurements as leads), fix the cause in the walker / steering / recovery code, and prove the fix with those tests plus a soak that counts "status moving, speed 0" ticks per ant (the count must be near zero outside real blockage). Then remove or shrink the workaround in `behaviours/nest` (`reachAndAct`, `approach`, `travel`) as far as the behaviour tests allow, and report what stays and why.
2. **Behaviour cost.** Measure simulation cost per tick, per system, for 300, 800 and 1,500 workers on the test world with autonomous behaviour (several runs, report the minimum; the machine is shared and loaded — compare shares and scaling, and use `FOUNDRESS_PERF_STRICT=1` for the strict bounds). Known offenders: the in-nest job board is rebuilt every tick although the design says every 2 s (give it an aligned, deterministic rebuild that survives save and load: either the board is plain data in state, or a loaded game rebuilds the identical board before its first tick — prove equality of state hashes for save -> load -> run versus an uninterrupted run); "think every tick when near a target" must not scale with population; per-tick allocations in the hot paths; outdoor perception. Budgets: 1.5 ms per tick for 800 in-nest ants and 1.2 ms for 500 outdoor ants on an idle machine.
3. **Action primitives.** Loading the crop from the pool (nurse and ration mixes), feeding the queen, helping eclosion, cannibalism, and unloading liquids into a chamber (GDD 02 §5.3) are done today by a local adapter (`behaviours/nest/careActs.ts`) with no pose: make them real action primitives with the lifecycle, timing and pose the design gives, usable by the possessed ant too, and switch the behaviours to them. Book the departure ration under its own ledger key if the colony ledger offers one (else report).
4. **Deliver first.** When a worker's task changes while it carries soil or food, it finishes the delivery before switching (GDD 02 §10.0); today only carried brood is covered. Give the behaviour runner the means and use it.
5. **Passive home-range deposits** (`HOME_DEPOSIT_PER_BU`) have no owner, so the scouts' bias away from home-marked ground never acts: implement the deposit where the design puts it and prove the scout bias with a test.
6. **Avoid markers.** The entrance flow field and the 16 BU planner cells graze avoid zones, and trail following inside an avoid zone is not weighted by the design's factor (GDD 02 §12.2): make planning and trail following respect avoid markers and remove the behaviours' own detour waypoints if they become redundant.
7. **Hygiene.** `src/sim/ants/behaviourRunner.test.ts` still asserts the old empty behaviour list; the no-op `perception` placeholder system in `src/sim/ants/index.ts` should go; `actions.verify` "stopAction" is red (find out why and fix the code or the test, with the reason); check whether `src/sim/colony/founding/clutch.ts` importing `src/sim/ants/actions` creates an import cycle (`ports.canLay is not a function` appeared depending on import order) and, if it does, break it from your side (lazy port lookup or a ports module without imports) and report it.

## Appendix: what the behaviour engineers reported
- In-nest behaviours: "an autonomous walker with a nest point goal often stands still for seconds with nav.status 'moving' and speed 0 (no desired direction). This happens near goals 0.4-2 BU away, and when upside down on a tunnel ceiling. A fresh request restarts the recovery ladder, so callers cannot fix it by re-requesting." Workaround now in `reachAndAct` and `approach`: let go of a ceiling above the target; think every tick within 4.5 BU of the target; treat a walk that stands still for 0.8 s near the target as finished, with a per-caller acceptance radius; when still out of reach, walk to a point 2 BU beyond the target. The old back-off steps asked for moves smaller than one nest voxel, which the walker cannot make.
- In-nest cost: best 6.39 ms per tick for 800 ants at machine load 23 (budget 1.5 ms); alarm checks are cached per chamber per board build; the egg search uses the spatial index; the board is rebuilt every tick because a loaded game could not rebuild a cached board.
- Not implemented for lack of a nest query (the other engineer adds it): the `internal-dump` state and the `midden-blocked` flag; such items are not offered as haul jobs and wait.
- Foraging: best 1.96 ms per tick for 500 outdoor ants under load (budget 1.2 ms); `outdoor/adapters.ts` imports colony internals (`countDelivery`, `accAdd`, `coreOf`) for want of a public count-only delivery function (the other engineer adds it: switch when it exists, else report); the allocator reassigns foragers that are still outside, so `exit()` hands the task back with reason `job:homing` until the ant is home; the beg from the pool books the departure ration as `transit`.
